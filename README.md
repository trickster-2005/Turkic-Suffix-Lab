# Turkic Suffix Lab

## English

An interactive, block-based morphology engine that shows how **Turkish, Kazakh and Uzbek** nouns take suffixes — and *why* each form is chosen. Built for teaching vowel harmony and consonant assimilation.

```
ev   + -lAr + -(I)m + -DA  →  evlerimde     (Turkish)
үй   + -LAr + -(I)m + -DA  →  үйлерімде     (Kazakh)
uy   + -lar + -(i)m + -da  →  uylarimda     (Uzbek)
                              “in my houses”
```

### Features

| Tab | What it does |
|---|---|
| 🔍 **Analyzer** (top of Builder) | Type any noun form and get it split back into stem + suffixes (e.g. evleri → 4 readings). Near-miss forms are diagnosed: evlarimde → “did you mean evlerimde? (vowel harmony)”. Unknown stems get a guessed split. |
| 🧱 **Builder** | Pick a word (or type your own), stack suffix blocks (number · 6 possessors · 6 cases), and compare three languages side by side. Each step shows the archiphoneme, the chosen allomorph, and a one-sentence rule highlighting the **trigger** and **chosen** sounds. Includes stem traits, Leipzig gloss and a shareable link. |
| ▦ **Paradigms** | Full possessor × case table for any word; click a cell to open it in the Builder. **Allomorph explorer** groups every word by the form it takes (e.g. all six Kazakh plurals -лар/-лер/-дар/-дер/-тар/-тер). |
| 🎯 **Practice** | Multiple-choice quiz. Wrong options are generated by switching off exactly one real rule, so every mistake teaches something. Score, streak, keyboard shortcuts. |
| 📖 **Grammar** | Eight bite-sized lessons plus an interactive Turkish vowel chart. |
| &lt;/&gt; **Code** | Live finite-state trace of the current input and a clean TypeScript reference selector. |

- Covers: vowel harmony (2-way / 4-way), Turkish D/T and Kazakh L/D/T assimilation, buffer consonants (y, n, s), pronominal *n*, consonant softening (kitap → kitabı), vowel drop (ağız → ağzı), and lexical exceptions (saat → saatler).
- UI in **English** (default) and **Traditional Chinese (Taiwan)**; **dark** theme by default with a light option; responsive from phones to desktops.
- **Sakha (Yakut)** is shown but disabled in this version.

### Run locally

No build step, no dependencies. Open `index.html` directly, or serve the folder:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

### Tests

```bash
node tests/engine.test.js
```

376 checks: golden forms for all three languages, distractor sanity checks, analyzer cases, and a generate → analyze round trip.

### Project structure

```
index.html          page shell
css/styles.css      design tokens, dark/light themes, responsive layout

js/data.js          lexicon (20 concepts × 3 languages)
js/i18n.js          UI strings, rule explanations, lessons (EN / zh-TW)
js/app.js           UI: builder, paradigms, explorer, practice, grammar, code
```

After editing `src/selector.ts`, regenerate the embedded copy with `node tools/build-snippet.js`.

### Notes

Rules are simplified for learners. Kazakh is written in Cyrillic with a simplified romanization; Latin input is auto-converted. Kazakh “2PL” is shown with the polite 2nd-person form -(ы)ңыз.

## 繁體中文

一個互動式、積木式的構詞引擎，展示**土耳其語、哈薩克語、烏茲別克語**的名詞如何接後綴——以及**為什麼**會選到那個形式。專為教授「母音和諧」與「子音同化」設計。

```
ev   + -lAr + -(I)m + -DA  →  evlerimde     （土耳其語）
үй   + -LAr + -(I)m + -DA  →  үйлерімде     （哈薩克語）
uy   + -lar + -(i)m + -da  →  uylarimda     （烏茲別克語）
                              「在我的房子（複數）裡」
```

### 功能

| 分頁 | 說明 |
|---|---|
| 🔍 **拆解**（組裝台上方） | 輸入任一名詞變化形，拆回「詞幹 + 後綴」（例如 evleri 有 4 種解讀）。接近但錯誤的形式會被診斷：evlarimde →「你是不是想打 evlerimde？（母音和諧）」。詞庫外的詞幹會給出推測拆法。 |
| 🧱 **組裝台** | 選一個詞（或自行輸入），疊加後綴積木（數・6 種領屬・6 種格），三種語言並排比較。每一步都會顯示抽象詞素、選定的詞素變體，以及一句話規則說明，並標出**觸發音**與**選定音**。另有詞幹特徵分析、逐詞素註解（Leipzig gloss）與分享連結。 |
| ▦ **變化表** | 任一詞的完整「領屬 × 格」表；點任一格即可帶回組裝台。**詞素變體探索**會把所有詞依所用形式分組（例如哈薩克語複數的六種形式 -лар/-лер/-дар/-дер/-тар/-тер）。 |
| 🎯 **練習** | 選擇題測驗。錯誤選項是「故意關掉一條真實規則」產生的，所以每次答錯都學得到東西。含得分、連對紀錄、鍵盤快捷鍵。 |
| 📖 **文法教室** | 八張簡短的文法卡片，加上可點選的土耳其語母音表。 |
| &lt;/&gt; **程式碼** | 以有限狀態機呈現目前輸入的即時轉移紀錄，以及精簡的 TypeScript 參考實作。 |

- 涵蓋：母音和諧（二重／四重）、土耳其語 D/T 與哈薩克語 L/D/T 同化、緩衝子音（y、n、s）、代名詞性 *n*、字尾濁化（kitap → kitabı）、母音脫落（ağız → ağzı）、詞彙例外（saat → saatler）。
- 介面支援**英文**（預設）與**台灣繁體中文**；預設**深色**主題，可切換淺色；手機到桌機皆為響應式設計（RWD）。
- **薩哈語（雅庫特語）**在此版本顯示為關閉狀態。

### 本機執行

不需建置、沒有相依套件。直接開啟 `index.html`，或啟動靜態伺服器：

```bash
python -m http.server 8000
```

然後前往 <http://localhost:8000>。

```bash
node tests/engine.test.js
```

### 備註

規則為學習者做了簡化。哈薩克語以西里爾字母書寫並附簡化拉丁轉寫，也可直接輸入拉丁字母自動轉換。哈薩克語的「2PL」以敬稱 -(ы)ңыз 呈現。
